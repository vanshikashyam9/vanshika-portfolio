Things I've built

Featured project · May 2026 – Present

RentScout AI

Before you send that deposit, check the listing.

GitHub ↗

Vancouver's rental market runs on scams that target people who don't know what rent should cost, don't know their tenant rights, and need housing urgently. I was one of those people. Every rental site shows you listings; none help you judge one.

The decision I'm proudest of

The first version ranked generated sample listings. It looked richer in a demo and helped no one find housing, and the scam check was quietly pricing listings against that same invented data. I cut rental search and rebuilt the price check on real CMHC rents.

  • Full-stack platform (~3,500 LOC) with 16 REST endpoints and a 7-table PostgreSQL schema.
  • Scam screen weighing payment red flags, manufactured urgency, and prices benchmarked against CMHC rents for that zone and bedroom count.
  • CMHC rent and vacancy data for 29 Metro Vancouver zones powering market comparison and affordability checks.
  • OpenAI API for neighbourhood insights and plain-English explanations of scam risk.
  • Dockerised, JWT + bcrypt auth, CI running lint, typecheck, build and API smoke tests.

Aug 2026

Mini-Redis

Redis is the in-memory database apps reach for when they need an answer in under a millisecond: caching, sessions, rate limits and queues.

A Redis-compatible server built from scratch in Python over raw TCP sockets, with no Redis libraries. It speaks the real RESP protocol, so the official redis-cli works against it.

  • PING, SET (with EX expiry), GET, DEL, EXISTS and EXPIRE, routed through a command dispatch table.
  • One thread per client and a lock-protected in-memory store, so concurrent connections stay safe; expired keys are cleared lazily on access.
  • Unit-tested, containerised with Docker, deployed on Railway, and paired with a Flask web UI that turns button clicks into RESP commands.
